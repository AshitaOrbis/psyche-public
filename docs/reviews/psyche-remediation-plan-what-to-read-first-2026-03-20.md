# What To Read First: Psyche Remediation Plan Approval Guide

Use this guide if you need a quick verdict on whether the remediation plan in [`analysis/BACKLOG.md`](../../analysis/BACKLOG.md) is approvable.

Current status as of 2026-03-20: **FAIL / NOT APPROVED**

## Decision Tree

```text
Need a 2-minute verdict?
  -> Read Final Executive Brief
     Shortest answer: the plan is not approvable as written.
  -> If that is enough, stop.

Need to know why approval is blocked?
  -> Read Critical Review
     Focus on: Executive Summary, Top 5 Critical Blockers, Revised Execution Plan.

Need the full technical analysis?
  -> Read Technical Assessment
  -> If the open question is package delivery into tier-3-nextjs, also read Delivery Matrix.

Need the formal approval gate?
  -> Read Decision Gate
     This is the pass/fail checklist, evidence standard, target dates, and sign-off record.

Need to know how to execute, if approval conditions are met?
  -> Read Executive Summary
     Use it for the mandatory pre-execution actions and corrected phase order.
  -> Then read Deferred Item Summary
     Use it to map each original backlog item to its reviewed disposition and target phase.
  -> Use Delivery Matrix during package rollout in Phase 3/4.
```

## Reading Guide

### 1. Start here for 2-minute verdict

Read [Final Executive Brief](./psyche-remediation-plan-final-executive-brief-2026-03-20.md).

Use it when you need the shortest possible answer to:
- Is the plan approvable as written?
- What must change before approval?
- What is the lowest-risk path forward?

### 2. Read this for why it matters (blockers)

Read [Critical Review](./psyche-remediation-plan-critical-review-2026-03-20.md).

Use it for:
- The core argument for why the current backlog order is unsafe
- The top approval blockers
- The revised execution plan

### 3. Read this for the full technical analysis

Read [Technical Assessment](../TECHNICAL-ASSESSMENT-2026-03-20.md).

Add [Delivery Matrix](../PSYCHE-WEB-NEXTJS-DELIVERY-MATRIX.md) if the decision turns on how `tier-3-nextjs` should consume `psyche-web`.

### 4. Read this for the approval gate

Read [Decision Gate](./psyche-remediation-plan-decision-gate-2026-03-20.md).

Use it for:
- The formal pass/fail status
- The eight mandatory gate conditions
- The objective evidence required before sign-off

### 5. Read this for how to execute (if approved)

Read [Executive Summary](./psyche-remediation-plan-executive-summary-2026-03-20.md) first, then [Deferred Item Summary](./psyche-remediation-plan-deferred-item-summary-2026-03-20.md).

Use them for:
- The corrected phase order
- The mandatory pre-execution actions
- The item-by-item mapping from the original backlog to the reviewed phases
